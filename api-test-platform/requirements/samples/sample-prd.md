# 电商系统需求说明（示例）

本文档用于验证需求分析链路，故意埋了几处典型的需求质量问题。

## 1. 用户登录

用户使用邮箱和密码登录。登录成功后尽快跳转到首页。

登录接口应在大约 1 秒内响应。

### 1.1 密码规则

密码长度至少 8 位，必须包含字母和数字。

连续登录失败 5 次后锁定账号，锁定时间待定。

## 2. 购物车

- 用户最多可添加 50 件商品到购物车。
- 购物车上限为 99 件商品。
- 未登录用户不能查看购物车。

### 2.1 数量修改

用户可以修改购物车中商品的数量，数量不能超过库存。

### 2.2 删除商品

用户可以删除购物车中的商品。

## 3. 订单

用户从购物车结算生成订单，支付成功后订单状态变为已支付。

## 4. 非功能要求

系统应保证高可用。
